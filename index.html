How To Use

Seed Map Update & Opt-Out

The seed map has recently received a large update. If you’re having issues with it, you can go back to the old version by clicking here.

This option will soon be removed, so please report any issues and discrepancies in the comments below.

Troubleshooting

If none of the below helps, please report in the comments and include your seed, platform and version, and coordinates.

Common user errors

If your in-game world doesn’t match the map here at all, it’s most likely due to one of the following:

  • you entered the wrong seed or coordinates (make sure there are no leading or trailing spaces)
  • you selected the wrong edition or version (the one used to generate the region you look at)
  • you used add-ons, mods or behavior/data packs that change world generation
  • (for slime chunks) you didn’t wait long enough, since they have a very low spawn rate even in slime chunks

Mixed version worlds

If you started your world on an older version, you must switch between the versions in the app. Always select the version that was used to generate the chunks you’re looking at.

Coastlines

By default, the coastlines for versions 1.18 and above don’t match up perfectly. This is not a bug, but rather because the map shows the underlying biomes instead of the exact terrain. Near coasts, ocean and river biomes often have land, while land biomes can be underwater.

You can enable the “terrain” option below the map to automatically adjust the colors of such mismatches.

Known limitations

Locations that don’t exist in-game

Many features are not 100% accurate, i.e., locations can be wrong or missing. These include:

  • Dungeons
  • End City Ships, and End Cities in general on Bedrock Edition
  • World Spawn Positions
  • Amethyst Geodes (near caves, mineshafts, etc.)
  • Desert & Jungle Temples
  • Enchanted Golden Apples
  • Nether Fossils and Dried Ghasts on Bedrock Edition

Various other structures such as villages and igloos can sometimes fail to generate in-game as well, but this should happen far less frequently than for the features mentioned above.

Inaccurate x/z coordinates

For some features like fossils, ruined portals and trail ruins the app currently only points to the center of the chunk they’re generated in. Since those structures are small, often buried, and can be offset 10-20 blocks from the chunk center, you might have to do some searching/digging to find them.

Missing y coordinates

The y coordinate isn’t shown for every feature. For structures that always generate on the surface or seafloor, this shouldn’t be an issue. In other cases, like mineshafts, strongholds and nether fortresses, the structures can easily be found by searching at different heights at the given x/z coordinates.

Unfortunately, this leaves some structures like fossils on Bedrock and ruined portals that spawn underground, which will require some manual effort to find.

Technical Issues

If the app is stuck or broken and won’t recover on its own, you can download a diagnostics report and send it to . You can also try resetting the app’s data.

Requirements

Seed

For technical reasons, you need to know the seed of your world to use Seed Map, unless, of course, you want to find a seed for a new world. If you’re playing SSP, the app is able to fetch the seed from your savegame. Alternatively, you can use the /seed command ingame. In SMP, you can use the same command if you have sufficient rights. Otherwise, however, you’re dependent on the server owner, who started the world and has access to the savegame and config files.

Browser

This app uses some relatively new web technologies. As a result, some features may be disabled for older browsers. I recommend using the latest version of a major browser such as Chrome, Firefox, Edge or Safari.

Usage

Setup

First, use the controls above the map to enter your world seed, Minecraft version and dimension (Overworld, The Nether or The End). You can also use a savegame to import the seed, or use the Random button to find new seeds. Invalid seeds like words will automatically be converted to a number in the same way Minecraft does it when creating a new world.

Use the expandable Features box to individually enable or disable all the supported structures and map features. Note that the available features depend on the currently selected version and dimension, and that most features will be hidden when zoomed out too far.

Below the map you can further customize the view settings, navigate to a specific coordinate and expand the map on the screen. You can also generate and share deep links and screenshots. Additionally, you can use the buttons at the bottom right inside the map to zoom in and out and to rotate.

Basic Map Controls

Mouse
  • Drag: move the map
  • Click on icon: show details
  • Right-click: place a marker
  • Mouse wheel: adjust zoom level
  • Double click: zoom in and exit expanded view
  • Shift + Double click: zoom out
  • Shift + Drag: zoom to selection
  • Shift + Alt + Drag: rotate
Keyboard
  • Arrow keys: move the map
  • R key: randomize seed
  • + and ‐ keys: zoom in/out
  • T key: toggle expanded view
  • S or / key: open the search
  • N and P keys: next/previous search result
  • Escape key: exit expanded view and close popups
Click the map first to enable keyboard controls.
Touchscreen
  • Drag: move the map
  • Tap: show position details at the bottom
  • Tap an icon: show details popup
  • Tap and hold: place a marker
  • Pinch: zoom in/out
  • Double tap: zoom in and exit expanded view
  • Two-finger twist: rotate

Advanced Features

Search: Use the search button at the top right of the map (or the S or / key) to find structures, biomes and other features around your current position. Matches are highlighted on the map, and the bar at the bottom lets you step through the results.

You can also build custom search queries: the sliders button opens the advanced search, where you combine a target with conditions on the nearby biomes, features and terrain. The ready-made queries under Presets are good starting points to adjust. Some examples:

  • Double witch huts sharing one AFK spot for a witch farm
  • Double dungeons: two spawners close together for an XP farm
  • Farm perimeters: an ocean monument surrounded only by deep ocean, or a pillager outpost on flat terrain for a raid farm
  • Base locations: flat plains bordering a cherry grove and ocean
  • The nearest rare biome patch: mushroom fields, pale garden, ice spikes, etc.
  • Sulfur Caves biome on the surface

Expanded Map View: Use the Expand button at the top right of the map or the T key on the keyboard to expand the map and stretch it across the browser window. You can exit this mode again via double tap/click, the T or Escape key, or via the button at the top right of the map.

Completed Locations: After selecting a structure, you can mark it as completed by using the checkbox in the popover window, which will make the icon semi-transparent. Tip: Hiding biomes makes it easier to find previously disabled locations again.

Custom Markers: After creating a temporary marker using right-click or tap-and-hold, you can click the save icon next to the label in the popover window and assign a name and color to make it permanent. You can edit and delete it in the same way. Once you created a marker for the current world and dimension, you can show and hide them in the Features box.
